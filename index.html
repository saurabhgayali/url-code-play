Try programs

Every example below is a real, executable URL.

Hello World

The smallest useful program.

/r/print/Hello%20World
Run →

Calculate

Variables and arithmetic composed together.

/r/set/x/10;add/x/20;multiply/x/3;print/x
Run →

Repeat

Run a command multiple times.

/r/repeat/5/print/Hello
Run →

Two pipelines

Five Hellos followed by five Worlds.

/r/repeat/5/print/Hello;repeat/5/print/World
Run →

Powers of Two

Repeat an arithmetic transformation.

/r/set/x/1;repeat/10/multiply/x/2;print/x
Run →

Compound Interest

Five periods of 5% growth.

/r/set/balance/1000;repeat/5/multiply/balance/1.05;print/balance
Run →

Multiple Variables

Independent variables can be manipulated in sequence.

/r/set/a/1;set/b/100;repeat/3/add/a/2;repeat/3/subtract/b/10;print/a;print/b
Run →

Read a Feed

Fetch a public RSS feed as plain text.

/r/read/https:/news.ycombinator.com/rss
Run →

One URL. One program.

Traditional programs live in files, repositories or applications.

URL Code puts the program directly into the address bar.

That makes every program naturally shareable, bookmarkable and reproducible.

The URL is the source of truth.

A tiny language

The current command set is intentionally small.

Command Example What it does
print print/Hello Print text or a variable
set set/x/10 Set a variable
add add/x/5 Add to a variable
subtract subtract/x/5 Subtract from a variable
multiply multiply/x/2 Multiply a variable
divide divide/x/2 Divide a variable
repeat repeat/5/print/Hello Repeat one command
read read/https:/example.com Fetch public text
```
```

Where could this go?

URL Code is an experiment, not a replacement for JavaScript.

input → transform → filter → calculate → output
The interesting question is how much computation can be expressed before a URL starts looking like a programming language.
