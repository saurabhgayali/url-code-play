URL Code

The URL is the program. Write commands in the path, share the link, it runs — and answers in plain text like an API.

Open the demo Source on GitHub 
/set/x/10/add/x/20/print/x     ->  30
/repeat/3/print/ha             ->  ha ha ha (one per line)
/read/https://example.com      ->  the page, as raw text

Features

Programs live in the URL

No database, no accounts, no saved state. A link is the whole artefact.

Plain-text, API-style output

Program URLs return text/plain — no HTML, no CSS, no client JavaScript.

Variables and arithmetic

set, add, subtract, multiply, divide — evaluated strictly left to right.

Repeat

repeat/<n> runs the single command that follows it n times.

/read as a CORS bypasser

Fetches any public URL server-side and returns raw text, so cross-origin rules never get in the way.

Piping

A double slash ends the read URL; commands after it keep running and append output.

Domain policy

blacklist.json holds a whitelist and a blacklist; a non-empty whitelist locks reads to those domains only.

curl friendly

Works the same in a browser tab, a terminal, or a shell pipeline.
